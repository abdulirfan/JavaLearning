# Ali Foundation Android App

Native Android starter built with Kotlin and Jetpack Compose.

## Screens
- Home
- Programs
- Get involved
- About

The app links to https://ali-foundation.org/ for current official information. It does not process donations or submit scholarship/volunteer applications. Verify the intended organization, current program availability, branding permission, and official contact details before public release.

## Build APK
The GitHub Actions workflow builds a debug APK on pushes to the `ali-foundation-apk` branch. Open **Actions**, select the latest **Build Ali Foundation APK** run, and download the `ali-foundation-debug-apk` artifact. Extract the ZIP to find `app-debug.apk`.

A debug APK is suitable for testing, not a signed production release.
